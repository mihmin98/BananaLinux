# What the Game Boy Pokémon companion takes from pret's disassemblies and the ROM hacks' forks of them:
# kiwami/tools/pret-extract.py reads this list and writes kiwami/tools/gbpk-extra.json. Only addresses, ROM offsets,
# ids and the ROM header's facts are taken; none of their code or data tables (kiwami/GB-POKEMON.md, *Where the data
# comes from*).
#
# A line a value; '#' starts a comment. <games> is one game or several joined by commas (crystal,gold,silver).
#
#   <game> release <repo> <build> <name>    a retail release: its SHA-1 from <repo>'s roms.sha1 (<build>.gbc), its
#                                           header's title and code from the Makefile's rgbfix flags for <build>.gbc,
#                                           and its symbols from <build>.sym on the repo's symbols branch. <name> is
#                                           No-Intro's region and revision. A game's releases must agree on every
#                                           value below, or the run fails.
#   <game> build <folder> <build> <sha1> <name>   a ROM hack's release, built by the user from its source at the
#                                           release's tag (<folder>, beside pret's; its HEAD must be the tag):
#                                           <build>.gbc in its working tree must have <sha1> (the release's; the
#                                           fork's roms.sha1 is pret's, left over), its header's title and code are
#                                           read from it, and its symbols from <build>.sym beside it. <name> is the
#                                           release's version
#   <game> hack <sha1> <name>               a ROM hack read as the game it patches: kiwami/tests/gbpk/roms.patches
#                                           must list <sha1> as a patch of one of the game's releases; its symbols
#                                           are the release's, and it isn't one of PokeDaisy's set
#   <games> ram.<key> <symbol>              a WRAM or HRAM address (bank 0 is C000-CFFF and HRAM, 1 the D000 bank)
#   <games> rom.<key> <symbol>              a ROM address (its bank and address in the bank's window)
#   <games> const.<key> <file> <name>       a constant from the repo's <file> (rgbds' const macros evaluated); several
#                                           files joined by + are read in that order, as the game includes them
#   item <NAME> <gen4> [ball]               an item upstream's logic knows by its Gen IV id (ui/src/nds/logic.cpp's
#                                           Item enum, its TMs from 328 and HMs from 420, the rods, the stones and
#                                           held items; upstream's ui/src/gba/gen3items.inc gives each), by its
#                                           constant's name in any game; ball: one of the balls (0 for a ball Gen IV
#                                           hasn't: 1000 + the game's own id, in the balls' pocket)
#   <games> items <file>                    the game's item constants: each item line's name the const macro gives
#                                           there is [its id, its Gen IV id] in the data file's items (a name it hasn't
#                                           is passed over: a DEF of another item's id, as pokecrystal's SAFARI_BALL, is
#                                           not an item), and the balls its balls
#   <games> keyitems <file>                 Gen I's KeyItemFlags (data/items/key_items.asm, "dbit TRUE ; NAME" an item
#                                           from 1, each name checked against the item constants' id): the TRUE ones'
#                                           ids are the data file's key_items
#   <games> types <file>                    the game's type constants: each one's id and the fork's name for it in the
#                                           data file's types (BIRD and CURSE_TYPE left out; one the fork doesn't
#                                           know stops the run), and those at or past SPECIAL its special types
#   <games> split <TYPE> physical|special|stats   an exception to the type constants' split, the source in a comment:
#                                           the type moved out of or into special, or to the attacker's stats
#
# A ROM hack with no source (Crystal Clear) is ported instead: kiwami/tools/gbpk-port.py, not pret-extract.py, reads
# its lines (pret-extract.py passes over every game with a port line) and writes kiwami/tools/gbpk-port.json. It is on
# its base game's ram., rom. and const. lines, which name the base's symbol, and has lines of its own:
#   <game> port <repo> <build> <sha1> <name>   one of its builds, by the user's ROM's SHA-1; ported from <build>.sym on
#                                           <repo>'s symbols branch and the base's ROM (its roms.sha1's). <name>'s
#                                           first word is the version, whose builds must agree on every value
#   <game> port.data <kind>.<key> <len>     found by the base's first <len> bytes at the symbol, once in the build
#   <game> port.code <kind>.<key> <pattern> found by a pattern of the build's bytes, once (gbpk-port.py's header):
#                                           a key the base hasn't (no base line) is found only so
#   <game> port.count const.<key> rom.<table> <size> <offset>   a table's length, its entries up to the lowest pointer
#   <game> port.same const.<key> rom.<table>   the base's constant, the table (port.data) being the base's bytes
#   <game> port.fixed const.<key> <value> <pattern>   a layout of its own its code holds in its shape (not as a byte):
#                                           <value>, if the pattern is found once in the build
#   <game> port.trainer const.<key> rom.<groups> <base's groups>   a trainer class: the build's class (in <groups>, a
#                                           bank and a pointer a class) whose first trainer has the name the base's
#                                           class (its constant, in <base's groups>, a pointer a class) has, once
#   <game> items|types from <base game>     the base game's items, by their names in the ROMs, and its types
# A line with no port.* method is found by the votes of the base's code that uses the symbol.
