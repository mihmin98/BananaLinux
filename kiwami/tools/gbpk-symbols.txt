# What the Game Boy Pokémon companion takes from pret's disassemblies: kiwami/tools/pret-extract.py reads this list
# and writes kiwami/tools/gbpk-extra.json. Only addresses, ROM offsets, ids and the ROM header's facts are taken;
# none of pret's code or data tables (kiwami/GB-POKEMON.md, *Where the data comes from*).
#
# A line a value; '#' starts a comment. <games> is one game or several joined by commas (crystal,gold,silver).
#
#   <game> release <repo> <build> <name>    a retail release: its SHA-1 from <repo>'s roms.sha1 (<build>.gbc), its
#                                           header's title and code from the Makefile's rgbfix flags for <build>.gbc,
#                                           and its symbols from <build>.sym on the repo's symbols branch. <name> is
#                                           No-Intro's region and revision. A game's releases must agree on every
#                                           value below, or the run fails.
#   <games> ram.<key> <symbol>              a WRAM or HRAM address (bank 0 is C000-CFFF and HRAM, 1 the D000 bank)
#   <games> rom.<key> <symbol>              a ROM address (its bank and address in the bank's window)
#   <games> const.<key> <file> <name>       a constant from the repo's <file> (rgbds' const macros evaluated)
